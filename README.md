# Silent Auction 🏷️

A simple Python implementation of a **silent auction**, where users can place bids, and the program determines the highest bidder with a clean console interface.

## Features ✨

- Collects bidder names and bids interactively
- Validates bids to ensure they are positive numbers
- Displays a custom ASCII logo from `art.py`
- Clears the console for a tidy experience
- Announces the winner with their bid amount

## Installation 📦

Ensure you have Python 3.x installed. No additional packages are required.

## Usage 🚀

Run the script using:

```sh
python main.py

Follow the prompts to place bids:
[Custom ASCII Logo]
What is your name?: Alice
What is your bid?: $100
Are there any other bidders? Type 'yes' or 'no'
yes
[Console clears]
What is your name?: Bob
What is your bid?: $150
Are there any other bidders? Type 'yes' or 'no'
no
The winner is Bob with a bid of $150
```
## Files 📂

- main.py - The main script for running the auction
- art.py - Contains the ASCII logo displayed at startup
